This repository contains the data and R code required to replicate the URZ analysis.

The files have been updated via the JQAS revision. The "df_called" dataset contains all called pitches from the 2023 MLB season. This can be uploaded directly or built from the raw data using the data prep code (raw data is available on statcast, not provided here). All code and results are included in the zip file, including code to fit the independent model via MLE and the 4 URZ models via Stan. Code and results for the cross validation analysis can be found here as well.
